# Dataset

This project uses the NASA Battery Dataset for lithium-ion battery degradation analysis and State of Health (SOH) estimation.

The dataset contains charge and discharge cycle measurements of lithium-ion batteries.

Due to dataset size and data management considerations, the raw dataset is not included in this repository.

## Dataset Source

NASA Ames Prognostics Center of Excellence

## Data Processing

The raw battery data are processed to extract relevant measurements and calculate battery State of Health (SOH).

The processed data are used for feature extraction, data representation, model development, and evaluation.
